WHAT WE ACTUALLY BUILT

A tiny pipe into a very large probability machine.

askcline is a transparent Bash wrapper around Cline’s OpenAI-compatible chat endpoint. It uses your existing local Cline session, submits one user message to a selected free model, and prints only the answer to standard output.

01YOUR PROMPTAll command-line arguments become one message.
→
02CLINE SESSIONThe wrapper reads your authenticated local token.
→
03FREE MODELOne completion. No browsing is added.
→
04STDOUTOnly the answer prints, so shell pipes stay clean.

WHY IT FEELS LIKE 2023

False premise in.
Polished “fact” out.

The wrapper does exactly what it promises. What it does not add is search, evidence, or a requirement to say “I don’t know.”

01

Leading premise

The prompt quietly asserts that an event, bureau, or inventor existed. A helpful model may continue that premise instead of challenging it.

02

No retrieval

This is a plain model completion. The wrapper adds no browser, archive, citation index, or independent check.

03

Specificity looks official

Names, dates, councils, quotations, and consequences make prose feel reported even when every supporting detail was generated.

04

Fluency is not evidence

A sentence can be clean, funny, and internally coherent while still being entirely unsupported.

THE RULEUse it for transformations.
Verify it for facts.Free is a price, not a fact-check.
