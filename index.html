THE LESSON

False premise in.
Polished “fact” out.

A completion endpoint can return text and tool-call requests. The harness is what executes tools, observes results, continues the loop, applies permissions, and requests validation evidence.

01

Workspace context

Cline reads the repository, instructions, rules, and relevant files before changing code.

02

Observation loop

Commands and tools produce results that become the next step's evidence.

03

Permissions

Auto-approval and command policies control autonomous execution.

04

Validation

The task contract requires named checks and honest reporting; humans still review the evidence and final diff.
